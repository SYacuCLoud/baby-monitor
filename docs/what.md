# 하는 일

- 집 안 카메라의 RTSP `stream1`에서 ffmpeg로 한 장을 받거나, 이미지 파일 한 장(`--image`)을 입력으로 받습니다.
- 픽셀 차이(numpy)로 움직임이 있는지만 보고, 변화가 없으면 모델을 부르지 않습니다.
- 이 PC의 모델이 세 가지 규칙(`face_cover`, `climbing`, `empty`)에 해당하는지 판정합니다. 엎드림은 별도 규칙이 아니고, 얼굴이 매트에 파묻히면 `face_cover`입니다. **실제 정확도는 검증하지 않았습니다.**
- 규칙에 걸리면 ntfy로 글만 푸시합니다. 감시가 멈추거나 모델이 계속 실패해도 푸시합니다.
- 푸시는 `--send`(GUI에서는 "푸시" 체크)를 켠 경우에만 나갑니다. 기본은 꺼짐입니다.
- 모델을 부른 판정마다 점수 한 줄을 `logs/scores.jsonl`에 기록합니다 (기본 켜짐. 사진은 기본으로 저장하지 않음). [점수 기록](score-log.md) 참고.
- 선택으로 Windows용 작은 창(`crib_gui.py`)이 있습니다.

하지 않는 일: 울음·호흡·체온 감지, 사진 전송(ntfy에 사진 없음), 클라우드 API 호출, 모델 학습, 사이렌.

**이건 실험용이며 의료기기가 아닙니다.** 알림이 없다고 괜찮은 상황이 아니고, 아기를 혼자 두는 용도로 쓰지 마세요.
