아기 침대 감시 구조와 흐름

이 PC에서만 클라우드 API 없음 알림은 글만 (사진 없음) 의료기기 아님 · 실험용

1. 실행 흐름 (watch.py)

화면 한 장 받기 (ffmpeg) 15초마다
집 안 카메라 stream1에서 한 장을 찍어 latest.jpg로 둡니다.
▼
움직임 확인 (motion.py) GPU 아끼기
직전 장과, 마지막으로 판정한 장을 둘 다 봅니다. 화면의 약 2% 이상 바뀌지 않으면 모델을 부르지 않습니다.
▼
판정 (judge.py) 기본 Jev
기본은 이 PC의 imajev-2b입니다. CRIB_MODEL=qwen이면 llama-server입니다. 사진은 클라우드로 보내지 않습니다.
▼
답 정리 (normalize) 코드 가드
앞뒤가 안 맞는 답을 고칩니다. 프롬프트 문구를 그대로 베낀 답도 걸러 냅니다.
▼
알림 (ntfy_alert.py) 10분 재알림 대기
같은 규칙은 10분에 한 번만, 글만 ntfy로 보냅니다. 사진은 절대 보내지 않습니다.
