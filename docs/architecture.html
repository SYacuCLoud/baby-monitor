Local Crib Monitor Architecture & Flow

로컬 전용 (Local Only) No Cloud API Text-Only Alert (No Photo on Push) Not a Medical Device

1. 실행 파이프라인 (watch.py)

RTSP Grab (ffmpeg) 15초 주기
LAN 내 Tapo 캠 stream1(TCP)에서 1프레임 캡처 (latest.jpg)
▼
Motion Gate (motion.py) GPU 보호
이전 프레임 대비 2% 이상 픽셀 변화 없으면 VLM 추론 생략 (skipped: true)
▼
판정 (judge.py) jev 기본
기본은 루프백 imajev-2b. CRIB_MODEL=qwen이면 llama-server. 클라우드로 프레임을 보내지 않음
▼
규칙 검증 & 보정 (normalize) 코드 레벨 가드
얼굴 노출 시 alert 취소, 프롬프트 문구 복사(환각) 차단
▼
알림 발송 (ntfy_alert.py) 10분 쿨다운
동일 규칙 10분 쿨다운 체크 후 텍스트만 ntfy 푸시 (사진 절대 전송 안 함)

2. 감지 규칙 (prompt.txt)

규칙 코드위험 상황비고
face_cover 이불/베개/옷이 입·코 가림 몸 덮는 이불은 정상 판정
face_down 매트리스에 얼굴 파묻힘 질식 고위험
climbing 침대 난간 기어오름 낙상 위험
empty 아기 및 보호자 모두 부재 이탈 감지

  "motion": true,

4. 핵심 설계 철학 (Ponytail Architecture)

경량 가드 (Motion Gate)
정지 상태에서는 무거운 Qwen VLM을 호출하지 않고 넘겨 GPU 발열과 전력 낭비를 방지해요.
개인정보 보호 (Privacy First)
아기 사진은 로컬 PC 밖으로 나가지 않아요. ntfy 알림에는 텍스트 요약만 실려요.
쿨다운 가드 (Notification Cooldown)
동일 위험 규칙은 10분간 중복 알림을 막아 부모에게 알림 폭탄이 가지 않게 제어해요.
